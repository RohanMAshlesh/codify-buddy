# Codify Buddy

An AI coding copilot for your terminal that knows your code, your docs and your tools.

```bash
npx codify-buddy
```

Codify Buddy indexes the repository you run it in, answers questions with
citations (`src/auth/session.ts:42-80`), and can plan and make changes —
reading files, editing code and running commands behind a permission gate you
control.

> Status: early development (P0 + P1). Connectors (GitHub, Confluence, MCP),
> the VS Code extension and team mode are on the roadmap — see
> [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
